## Bonus — Interview Questions & Quick Concepts

A large bank of short-format interview Q&A videos covering:

- Component naming conventions & uppercase rule
- Named vs default exports
- JSX rules (single parent element, ternary operators, conditional rendering)
- `useState` vs `useEffect` pitfalls (stale state, infinite loops)
- Reconciliation & keys in `.map()`
- Automatic batching & re-render behavior
- `useEffect` vs `useLayoutEffect` vs `useMemo` vs `useCallback`
- Higher-Order Components (HOCs)
- React 19.2 features: `Activity`, `useEffectEvent`
- HOC, custom hooks (`useToggle`), and `useRef` tricks (previous state)
- React vs jQuery forms, React vs Redux state handling
